# ☕ Capítulo 04: Sincronización Daily Scrum

## 1. Funcionamiento del Registro Diario
La solapa **Daily Scrum** permite a cada miembro del equipo responder las tres preguntas clásicas de sincronización ágil:
1. **¿Qué completé ayer?**
2. **¿Qué planeo avanzar hoy?**
3. **¿Tengo bloqueos o impedimentos?**

## 2. Almacenamiento Transparente
- Cada registro de Daily se guarda como un comentario formateado dentro de un Issue específico con el label `daily-scrum`.
- Permite mantener el historial de sincronización del equipo auditable, con fecha, hora y autor directamente en el repositorio.
